# FlickChain《一弹到底》

手机优先的 Web 3D 物理接力游戏。所有硬币公共共享：一杆合法命中唯一目标后获得 1 分，原币在结算后消失，玩家从目标币的最终位置继续弹射。

当前状态（2026-10-11）：单人5关与本地双人可玩，支持起手自由选币、合法接力锁币和默认圆桌。游戏已接入用户调整蒙皮的动画手，手背朝上、缩放到上一版的80%、使用肤色材质；满蓄力力量提高到原来的2倍，修复桌边异常位移，并加入开局轻落桌与录音音效。

108项自动化测试、五关完整生产解法回放、类型检查和构建通过。本轮浏览器鼠标验证了入场、暂停恢复、选币与第二关通关；历史版本另有模拟触摸检查。真机触摸、手机性能、实际听感与线上发行尚未验收。阶段状态见 [开发进度](docs/PROGRESS.md)，本轮证据见 [手模型、物理与音效验收](docs/validation/2026-10-11-hand-physics-audio.md)。

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址。开局硬币依次轻落桌，落稳后开放选币。空白区域拖动旋转 3D 视角；入关或双人换人后可选择任意公共硬币，首杆发射前可反复切换。合法命中后，必须从刚击中硬币的最终位置继续，不能重新选币。选币后镜头推近当前币，手放在金币正后方，食指待机平行桌面；按住手或当前币蓄力时食指逐渐弯曲、指尖回收，高蓄力时手会轻微抖动，松手沿当前视角前方弹射；力度只由按住时长决定，1.25秒蓄满。减少动态效果设置会关闭抖动和入场落桌动画。近景中可通过旋转视角寻找其它硬币。一杆的目标只统计源币直接接触的硬币，双人犯规停稳后换人，换人后重新开放起手选币。

```sh
npm test
npm run validate:levels
npm run build
npm run preview
```

`dist/` 是静态产物；资源采用相对基址。音频由用户操作解锁，存档失败仅提示，仍可游玩。关卡与物理参数改动后须重新生成并验证完整解，步骤见 [关卡测试说明](tests/levels/README.md)。

## 模型、物理与音效

手模型以用户调整的 [pointing-hand-rigged.blend](blender/pointing-hand-rigged.blend) 为编辑源，[flick-hand.blend](assets/flick-hand.blend) 为游戏适配副本，[flick-hand.glb](public/models/flick-hand.glb) 为运行资产。导出保留用户骨骼和蒙皮，将 `Index_Curl` 的12–36帧映射为一秒 `FlickCharge`，运行时按蓄力比例采样。袖口开口与原模型拓扑保留，旧封闭连体手属于历史版本。加载失败可用“重建本局”重试。重导方法和资产指纹见 [模型说明](assets/README.md)。

默认圆桌直径1.6米，显示、点击与物理边界一致。`wood-standard-v2` 最大冲量为0.048 N·s，公共固定步120 Hz，每步执行两个240 Hz Rapier内步，以保持满力度下薄障碍的碰撞。桌边以币心是否越界判断倾倒；开局落桌仅改变呈现，不改变关卡物理初始布局。

硬币撞击、木桌撞击和轻落桌使用真实 CC0 录音；滑行是更柔和的低频合成摩擦层，按桌上移动渐弱。静音、暂停和切关会清理当前声音。作者、来源与剪辑说明见 [音效来源](assets/audio-sources.md)。

本仓库上传用于保存源码、可编辑模型、音频及验证记录；没有配置自动部署工作流，GitHub上传不代表线上部署或CrazyGames发布。

## 执行顺序

物理手感原型 → 整杆接力规则 → 单人/本地双人 MVP → Worker AI → 材质与 20 关内容 → 性能与平台发行。

PRD 规定产品行为，架构规定实现边界，任务计划规定顺序与完成条件。出现冲突时先更新决策记录并同步三份文档，避免各模块自行选择规则。详细调校参数均为候选，需实际浏览器与设备验证。
