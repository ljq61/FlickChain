# FlickChain 交互 v2 验证记录

日期：2026-10-10｜范围：交互规则、表现与音效｜环境：macOS + Chrome 154 无头（ANGLE Metal 真 GPU）+ CDP 合成指针

## 1. 本轮变更

- **选币规则**：点选硬币立即开始，删除二次确认；ready 阶段只要本杆未弹射，点其他公共币可随时切换当前币（`GameSession.selectCoin` 放开 ready 阶段；切换只改主控币，不影响分数与残局）。
- **弹射交互**：力度改为按住时长（160ms 起步阈值、1.25s 满档），删除拖拽距离蓄力与画面内"力度 xx%"数字。当前币后方平放程序化手指（两段胶囊 + 指甲 + 掌根），指尖抵住币后缘；按住手指或硬币时手指逐步弯向硬币、随力度平方发抖，松手弹射。
- **表现**：硬币恢复金色（黄铜 0xdab463 系，metalness 0.78 + 清漆）；木桌加深为胡桃色并配径向暗角；场景环境贴图强度 0.7→0.3（消除金属面洗白，全场景更沉稳）；选中/当前币保留琥珀色呼吸脉冲发光，移除全部 3D 文字标签（当前币/已选币/力度）。
- **音效**：币-币碰撞改为非谐波金属泛音 ringing（4 分音、随机微失谐、0.24s 衰减）；障碍碰撞叠加金属泛音与低频木声；新增滑动金属摩擦声（噪声 + 3.2kHz 带通，音量跟随最快移动硬币速度）。

## 2. 验证证据

### 单元与构建

- `npm run typecheck`：通过。
- `npm test`：55 通过、1 跳过。`GameSession.test` 新增 ready 阶段切换断言（挑战与对战均可切换、被击落后仍不可选）；`Shell.test` 改为断言无确认按钮与新文案。
- `npm run build`：通过。

### 浏览器 E2E（真实 GPU）

流程：菜单 → 进入关卡 1 → 点币 a 立即 ready → 点币 b 切换当前币 → 旋转视角 → 按住手指 790ms → 松手弹射 → 合法命中 +1 → 关卡 complete。全程控制台零错误（favicon.ico 404 为项目原有）。

- 切换生效的像素证据：切换后发光的当前币位于画面中心，另一枚币出现在左侧约 122px 处，镜头焦点随主控币移动。
- 蓄力表现的像素证据：手指肤色可见面积与轮廓随力度递进变化（0→0.4→0.63），高力度帧间抖动可见。
- 力度过大的对照组：0.76 档蓄力会把被击币撞出桌面（FALL 犯规、剩余 1、failed），物理与规则判定正确。
