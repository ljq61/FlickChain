## 2. 本轮采用的设计默认值

以下用于让任务可执行，是规划决定，不表示用户逐项确认或已试玩验证。

| 编号 | 决定 | 原因 / 重新评估条件 |
|---|---|---|
| D-01 | MVP 为 Phase 1–3：木桌标准币、CLEAR_ALL、5 个验证关、本地双人 Last Coin、基础教学/音效/进度 | 先验证角度、力度与接管后走位；Phase 5 扩至 20 关 |
| D-02 | 对战首版以剩余硬币 ≤1 时累计合法得分判胜；同分显示平局、允许再来一局 | 避免早期引入目标分数与剩币数冲突、无限加赛；Score Race 后续 |
| D-03 | 犯规零分，不删除仍存活的原币；保留物理残局。原币掉落且剩 ≥2 时，对方选择新的主控币 | 延续源方案；若试玩出现故意犯规主导玩法，再评估规则，不暗中回滚 |
| D-04 | 超过模拟步数上限仍未静止，判 TIMEOUT 犯规；保存诊断、冻结终态并清零速度；合法支撑才进入对战模式结算，悬空/非法支撑进入错误恢复，提供重建/返回 | 防止无限等待和杆外掉落；只删除已确认掉落币，冻结不宣称正常静止，不补分或回滚 |
| D-05 | 首个有效碰撞只提供反馈，不兑现分数。确定犯规立即提示并锁输入，安全静止或超时清理后才交接 | 保留完整物理过程，避免下一杆与上一杆并发 |
| D-06 | 一个 shared production physics + full-shot resolver 同时供实玩、AI 与关卡解回放 | 防止预测与实玩规则分叉；不承诺无条件跨设备逐位确定性 |
| D-07 | 120 Hz 固定步为起始候选，Phase 1 比较 60/120 Hz；渲染降级不改变当前关卡物理配置 | 当前没有移动端性能测量 |
| D-08 | 首版暂停采用会话级冻结；重试/返回销毁旧会话并拒收旧异步结果 | 避免隐藏页面追赶、Worker 回包污染和重复结算 |
| D-09 | Battle 首局 Player 1 先手，再来一局交替；起手和每次犯规换人先从公共币中选币确认；犯规时原币存活仍保留其真实终点供下家选择 | 当前实现与 PRD 一致；阶段 3 试玩评估先手优势与选币节奏 |
| D-10 | 2026-10-10 交互 v2：点币立即开始（无二次确认）；ready 阶段只要本杆未弹射，点其他公共币可随时切换当前币；切换只改主控币，不产生分数或残局变化 | 用户裁定选币不应被锁定；切换不触及得分/犯规/残局，核心判定仍按整杆结算 |
| D-11 | 弹射力度只由按住时长决定（160ms 起步、1.25s 满档）：当前币后方平放程序化手指，指尖抵币后缘，蓄力时手指弯向硬币并按力度平方发抖；画面内不显示数字/文字标签。金属感声音：币-币碰撞为非谐波金属泛音 ringing，滑动为随速度的持续金属摩擦，障碍碰撞叠加金属泛音 | 用具象手指替代数字与拖拽距离；证据见 [交互 v2 验证记录](validation/2026-10-10-interaction-v2.md) |

可逆的 UI/素材调校可在阶段内迭代。改变公共币、得分、犯规、残局、胜负等核心规则需先更新 PRD 和本表，并重新验证已有关卡解。

## 3. 官方能力核对

本轮核对日期：2026-10-09。文档证明能力存在，不证明本项目实现正确。

- [OpenAI Subagents](https://learn.chatgpt.com/docs/agent-configuration/subagents)：项目角色使用独立 TOML；模型与推理强度随角色设置。详见配置验证记录。
- [Rapier Colliders](https://rapier.rs/docs/user_guides/javascript/colliders/)：圆柱碰撞体、质量与接触材质可配置。具体参数须在游戏中调校。
- [Rapier Serialization](https://rapier.rs/docs/user_guides/javascript/serialization/)：支持物理世界快照；业务状态需要独立保存。
- [Rapier Determinism](https://rapier.rs/docs/user_guides/javascript/determinism/)：复现依赖满足引擎与输入条件；本项目需在目标环境实测一致性。
- [Vite Web Workers](https://vite.dev/guide/features#web-workers)：Worker 可由构建工具处理；必须实际检查产物及部署资源路径。

CrazyGames SDK、广告、上传限制、Basic/Full Launch 条件不在本轮确认范围。进入 Phase 6 时重新读取当期官方文档，不把历史聊天中的数值作为当前平台要求。
